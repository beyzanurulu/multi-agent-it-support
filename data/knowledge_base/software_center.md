# Software Center ile Yazılım Kurulumu

## Çözüm Adımları
1. Başlat menüsünden Software Center'ı açın
2. Kurmak istediğiniz uygulamayı arayın
3. 'Yükle' butonuna tıklayın
4. Kurulum bitince bilgisayarı yeniden başlatın

## Ne Zaman Talep Açılmalı
Adımlar sorunu çözmezse destek talebi açın.
