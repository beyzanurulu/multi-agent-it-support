# VPN Kurulumu

## Çözüm Adımları
1. Software Center'dan GlobalProtect istemcisini kurun
2. Portal adresi olarak vpn.example.local girin
3. Kurumsal kullanıcı adı ve şifrenizle giriş yapın
4. MFA onayını verin
